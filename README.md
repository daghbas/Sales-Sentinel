# Sales Sentinel
## نظام التنبؤ الذكي بانخفاض المبيعات

مشروع Flask ثنائي اللغة لتحليل المبيعات اليومية الحقيقية، مقارنة نماذج التنبؤ زمنيًا، حساب فواصل عدم اليقين واحتمال الانخفاض، وإدارة التنبيهات والتقارير والمستخدمين والصلاحيات.

## مصدر البيانات الحالي

النسخة الحالية مبنية حصريًا على ملف **Redsea Dataset** اليومي الحقيقي والمجهول الهوية:

- 2,700 صف خام.
- إزالة 5 صفوف متطابقة فقط.
- 2,695 صفًا نظيفًا.
- 1 يوليو إلى 31 أكتوبر 2023.
- 121 يوم بيع فعلي من أصل 123 يومًا تقويميًا.
- 352 رمز منتج، و23 فئة، و4 قنوات بيع مشفرة.
- لا تستخدم بيانات SAMA الأسبوعية في التدريب الحالي.
- لا توجد مبيعات صناعية أو تنبيهات ثابتة.

التفاصيل والبصمة في `data/source_manifest.json` و`docs/data_audit.md`.

## البنية

```text
app/                 Application Factory, Blueprints, models, services
api/index.py         Vercel Python entrypoint
data/raw/            Original legal source files
data/processed/      Clean transaction and daily aggregate CSV files
instance/            Ready SQLite database
migrations/          Alembic migration from an empty database
models/              Selected model configuration and real metrics
scripts/             Rebuild, training and live screenshot automation
tests/               Data, model, security, route and report tests
docs/                Audit, dictionary, metrics, limitations and run guides
screenshots/         Live application screenshots generated by CI
```

## التشغيل على Windows

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements-training.txt
python scripts\build_from_redsea.py
python run.py
```

ثم افتح `http://127.0.0.1:5000`.

## النموذج

تمت مقارنة خطوط أساس وExtra Trees بتقسيم زمني دون Shuffle. النموذج الفائز هو **Moving Average 7 Days** لأنه حقق أقل WAPE في الاختبار الزمني. النتائج الحالية ضعيفة إنتاجيًا بسبب قصر الفترة:

- MAE: 18,842.85 ر.س
- RMSE: 27,515.69 ر.س
- WAPE: 70.85%
- sMAPE: 71.39%

لذلك يسمح النظام بتصور 7 و30 يومًا مع فواصل عدم اليقين، ويمنع 90 يومًا آليًا حتى يتوفر 365 يومًا تاريخيًا على الأقل.

## الاختبارات

```bash
pytest -q
DATABASE_URL=sqlite:////tmp/sales-sentinel-migration.db alembic upgrade head
```

GitHub Actions يعيد بناء المشروع من الملف الخام، يشغل الاختبارات، يشغل التطبيق الحي، ثم يلتقط الشاشات من Chromium.

## Vercel

يوجد `vercel.json` و`api/index.py`. على Vercel تُنسخ قاعدة SQLite الموثقة إلى `/tmp` لتقديم نسخة عرض؛ أي تغييرات أثناء الجلسة مؤقتة. التشغيل المحلي هو نمط SQLite الدائم. للاستخدام الإنتاجي على Vercel يجب ضبط `DATABASE_URL` لقاعدة دائمة متوافقة.

## القيود

- معرض واحد في جدة وفترة أربعة أشهر.
- لا تتوفر بيانات المخزون أو معرفات الحملات التفصيلية.
- رموز قنوات البيع غير موثقة بقاموس رسمي.
- يومان مفقودان يُستكملان خطيًا لأغراض استمرارية النموذج فقط، ولا يُسجلان كمبيعات فعلية.
- الدقة الحالية Pilot ولا تصلح لاتخاذ قرار آلي أو نشر إنتاجي.
